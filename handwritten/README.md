# Handwritten explanations

The assignment requires **photographed handwritten notes**, one page per fix. This
folder intentionally contains no images: handwriting cannot be generated, and
placeholder/fake images would misrepresent the submission.

Write each page by hand and drop the scans here with the filenames below. The
bullets in `../NOTES.md` / this list are prompts only — write in your own words.

Suggested files:

- `01-search-bug.jpg` — SQL operator precedence (archived leak + status filter bypass)
- `02-validation-bug.jpg` — invalid status / page returning 500 instead of 400
- `03-performance-bug.jpg` — artificial Thread.sleep removed from the controller
- `04-react-bug.jpg` — page not reset on search/filter change; error state swallowed; search debounce

For each page cover: Location, Symptom, Root cause, Fix, Verification.
